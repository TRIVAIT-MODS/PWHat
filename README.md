# PWGood Hat (Blockbench Plugin)

Плагин для Blockbench, добавляющий формат проекта «PWGood Hat» для создания головных уборов под персонажа PWGood (голова-раздатчик).

## Возможности

- **Формат проекта «PWGood Hat»**: доступен на главном экране при создании нового проекта.
- **Модель раздатчика**: в центре сцены (`0, 8, 0`, размер 16×16×16) отображается блок раздатчика с текстурами лица, верха и боковин.
  - Видимость раздатчика можно переключать в настройках (`Настройки` → `Предпросмотр`) или через меню `Вид` (`Toggle Dispenser Guide`).
- **Ракурс камеры**: в меню углов камеры (`Angles`) добавлен пресет `Dispenser Default Angle` (изометрия 2:1, ортографическая проекция).
- **Вкладка и окно Render**:
  - На 3-й вкладке (вместо Animate) размещена кнопка **Render**. Также вызывается клавишей **F4** или через меню `Файл` → `Экспорт`.
  - Превью в реальном времени с ортографической камерой (вертикальные грани строго параллельны и не сходятся в перспективу).
  - Настройка ракурса: пресеты (`Dispenser Default Angle`, `Front`, `Side`, `Top`, `Back`), ручные углы (Pitch, Yaw, Roll) и зум.
  - Слайдер `Hat Y Offset` для точной подгонки высоты посадки шапки на раздатчике.
  - Поддержка хромакея / гринскрина с выбором цвета либо рендер с прозрачным фоном.
  - Маска раздатчика при рендере: раздатчик не виден на финальной картинке, но скрывает части шапки, находящиеся позади него.
  - **Экспорт в PNG** в разрешениях от 256×256 до 2048×2048.

## Установка

1. Скачайте файл `pwgood_hat.js` из раздела [Releases](https://github.com/).
2. В Blockbench перейдите в `Файл` → `Плагины...` (`File` → `Plugins...`).
3. Нажмите кнопку **«Загрузить плагин из файла»** (иконка папки в верхней панели).
4. Выберите скачанный файл `pwgood_hat.js`.
